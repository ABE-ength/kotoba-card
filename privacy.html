ことばカード プライバシーポリシー

最終更新日：2026年11月6日

1. このアプリについて

ことばカード（https://abe-ength.github.io/kotoba-card/ およびWindows用アプリ）は、英単語を覚えるための個人向けの学習アプリです。

2. 保存するデータと保存場所

  • 登録した単語・意味・例文・メモ・理解度などの学習データは、利用者の端末の中（ブラウザ内またはパソコン内）に保存されます。
  • 開発者のサーバーはなく、開発者が利用者のデータを受け取ったり、見たりすることはありません。

3. Googleドライブ同期（任意）

  • 利用者が「Googleでログイン」を選んだ場合に限り、Googleドライブの「アプリ専用の隠しフォルダ」（スコープ：https://www.googleapis.com/auth/drive.appdata）に、学習データのファイル（kotoba-sync.json）を1つ保存し、端末間で同期します。
  • アプリ専用フォルダ以外のファイルを読んだり、変更したりすることはありません。
  • Googleアカウントのパスワードがアプリに渡ることはありません。ログインの許可（アクセス用・更新用の鍵）は、利用者の端末の中にだけ保存されます。
  • Googleから受け取ったデータは、同期の目的にだけ使い、第三者に提供・販売したり、広告に使ったりすることはありません。
  • 許可はいつでも、Googleアカウントの「サードパーティ製のアプリとサービス」から取り消せます。アプリの「ログアウト」でも取り消されます。

Google APIから受け取った情報の使用・転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

4. インターネット検索

例文・発音記号・辞書の意味を調べるとき、登録した単語の文字だけを、次の公開サービスに問い合わせます：Wikipedia、Wiktionary、Wikinews、Free Dictionary API、Tatoeba。意味・メモ・学習記録などは送りません。この検索は設定で止められます。

Privacy Policy (English summary)

Kotoba Card is a personal vocabulary study app. Study data is stored only on the user's own device. If the user chooses to sign in with Google, the app stores a single sync file in the user's Google Drive app data folder (scope: drive.appdata) and uses it only to sync the user's own devices. The app cannot access any other Drive files, does not share or sell Google user data, and does not use it for advertising. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the user's Google Account settings. Contact: abesouichi@gmail.com
